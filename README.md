# Sleep Deprivation Informational Website

A lightweight, responsive web application designed to educate users on the causes, symptoms, and health risks of sleep deprivation. Optimized for deployment on Render and integration with Google Ads/AdSense.

## Features
- **Responsive Layout:** Works seamlessly across desktop and mobile devices.
- **Fast Performance:** Built with plain HTML, CSS, and an Express.js backend.
- **AdSense Ready:** Pre-configured placeholder containers for Google Ads integration.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3
